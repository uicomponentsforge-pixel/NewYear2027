# New Year 2027 Countdown

An interactive, live web countdown application celebrating the arrival of New Year 2027 with dynamic neon visual effects, customizable timezone selection, a live clock, and optional celebration sound effects with HTML5 Canvas fireworks.

## Features

- **Live Countdown**: Real-time breakdown of remaining days, hours, minutes, and seconds until January 1, 2027 at midnight in the selected timezone.
- **Timezone Selector**: Easily switch between supported timezones to see when New Year 2027 arrives around the globe.
- **Local Clock**: Displays the current local time in the selected timezone.
- **Interactive Fireworks & Visuals**: Smooth HTML5 Canvas particle system animating background firework launches and celebrations.
- **Celebration Audio**: Synthesized Web Audio API sound effects for firework bursts (can be toggled on/off).
- **Responsive & Accessible Design**: Dark theme with neon accents, optimized for both desktop and mobile screens.

## File Structure

- `index.html`: Main HTML markup containing countdown displays, settings panel, and canvas element.
- `style.css`: Modern CSS styling, layout grid, typography, custom color variables, and keyframe animations.
- `script.js`: Core JavaScript application logic for timezone conversion, countdown timers, canvas particle physics, and Web Audio API synthesizer.

## Getting Started

No build tools or external dependencies are required. To view the app locally:

1. Clone or download this repository.
2. Open `index.html` in any modern web browser.
